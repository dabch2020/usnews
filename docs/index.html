BIO——NVIDIA 今天发布了 NVIDIA BioNeMo Agent Toolkit，它为代理生命科学时代提供了特定领域的工具和技能。该工具包包含 NVIDIA 生命科学库、工具和开放模型十多年的价值，使 AI 代理、科学家和实验室能够通过收集证据、对发现结果进行推理、运行计算实验并推荐下一步最佳步骤来加速发现，从而协同工作。
